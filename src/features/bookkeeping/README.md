# תורת הנהלת החשבונות

מקור המיון התפעולי הוא handbookData.ts, בגרסה שאושרה ב־29.10.2026 על בסיס docs/paperless-office-2026-10-27/office-handbook.json שבעותק המקורי. BookkeepingHandbook מציג את אותו מקור בעמוד המשרד ובידע המקצועי. ההמחשה ב־docs/proposals היא צילום מצב של ההצעה, ולא מקור לעריכה שוטפת.

- אין נתוני לקוחות או חריגים פרטיים במילון.
- מספר קוד, שם המיון וסימון הבית הם נתונים נפרדים. משני אינו אחוז ההכרה.
- סעיף מיסים ואגרות מסומן לבירור הגדרה: סימון הבית שנצפה בקטלוג אינו הוראה להפחית אגרת עסק.
- סף ציוד קל הוא מדיניות משרדית; אין להציגו כחוק מס או לשנותו מתוך מחקר אוטומטי.
- expenseDictionary הוא מחקר מס נפרד, אינו הוראת מיון לפייפרלס. סנכרון שמות המקור בידע: node scripts/knowledge-corpus.mjs.
- הסוכן המופיע בקטלוג הוא תוכנית בלבד: אין handler, הרשאות או כתיבה לפייפרלס במסגרת זו.
