- **נספחים**: 1320 (לכל עסק, לא בעסק זעיר), 1321 (שכ״ד 10% / רגיל), 1322, 1324, 1342, 1343, 1344, 1399י, 119, 6111 — לפי הנתונים.

## 6. תיק המס
- ישות חדשה מתשובה → «הוסף לתיק» (הצעה). ישות קיימת שתשובה סותרת → «סותר את התיק» + «עדכן בתיק» (הצעה עם תמונת המצב). אישור על תיק שהשתנה בינתיים → נדחה כסתירה. תוצר שאושר → «לבדיקה» (נוסף / הוסר / השתנה).
- הצהרות, פרטים שהכרטיס לא מחזיק וחשבון להחזר — עובדות שנת המס (`filing.declarations`, `filing.identity`, `filing.refundAccount`). פער כרטיס מתועד: שם האב, חודש שחרור וחודשי שירות, קוד תואר, תאריכי עלייה — אין להם שדה בכרטיס.
