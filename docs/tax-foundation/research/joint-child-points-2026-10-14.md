# נקודות ילדים בחישוב מאוחד, 66(ד), מס יסף לכל בן זוג, וקביעת בן הזוג הרשום (2025, 2026)

נכתב 14.10.2026. ממשיך את `spouses-joint-separate-numeric-2026-10-13.md` (להלן «המחקר הקודם») ומכריע את הפתוחים (ד)-1, (ד)-4, (ד)-5 ואת הקלט «מי הרשום». לפי הנחיית גיא: אי־ודאות נפתרת במחקר, לא ב«אישור משרד» ולא בבחירת הקצה השמרני.

## שורה תחתונה לרו״ח

1. **(ד)-1 הוכרע: בחישוב מאוחד אין נקודות זיכוי בעד ילדים — לאף אחד מבני הזוג.** לא לרשום, לא לאם. ההשפעה היחידה של ילדים במאוחד היא 2.0 במקום 1.75 נקודות לפי סעיף 38 (או 1.75 במקום 1.5 לפי 39). נקודות ילדים של זוג נשוי קיימות רק בחישוב נפרד, ושם רק כנגד המס על היגיעה האישית של ההורה. **הטווח J-min/J-max מתבטל: J = J-min.**
2. **(ד)-5 הוכרע: כשלבני הזוג מקור הכנסה משותף שלא עמד בשלושת התנאים — כל משק הבית במאוחד**, גם הכנסה עצמאית אחרת של בן הזוג. עמדת הרשות מפורשת, והיא תואמת את לשון 66(ד) מאז 2014.
3. **(ד)-4 הוכרע: בחישוב נפרד מס יסף נבחן לכל בן זוג בנפרד, עם סף משלו.** הכנסה שאינה מיגיעה אישית — כולל הכנסה בשיעור סופי (שכירות 10%) — משויכת לצורך מס יסף לפי 66(א)(2), (א)(3) ו־66(ב), כמו בחישוב המס. כך קובעת הוראת ביצוע 9/2015, שעדיין בתוקף.
4. **בן הזוג הרשום אינו שאלה משפטית אלא נתון ברישומי הרשות.** מקור האמת הוא שע״מ (המדבקה / שאילתת ISUM / פורטל המייצגים). כשאין נתון מאומת, אפשר לגזור **חזקה** לפי 64ב(א). אבל הזהות משנה מס (דוגמה ה), ולכן מס משק הבית בזוג כזה מוצג רק אחרי אימות מול שע״מ. המוצר כבר יודע לקרוא את זה.
5. **נשאר פתוח באמת:** דבר אחד בלבד. אין פסק דין או דברי הסבר שדוחים במפורש טענה של נישום שהרשום רשאי לתבוע 66(ג)(1א) בתוך שומה מאוחדת־חובה. כל מסמכי הרשות שנקראו סותרים את הטענה, ולכן המנוע לא מחשב אותה. ההשפעה אם נישום יזכה בה ב«ויכוח»: עד נקודות הטור של הרשום × 2,904 ₪ (בדוגמה א: 5,808 ₪). זה **לא** טווח במנוע. זו הערת סיכון בלבד (ראו ו).

### א.2 הכלל למוצר (אלגוריתם)

```
childPoints(spouse, calc):
  if calc == JOINT:                       // מאוחד — בין חובה (66(ד)) ובין «הזול» שהרשות בחרה
      return 0                            // לשניהם. אין J-max.
  if calc == SEPARATE or SINGLE_EARNER_1A:
      col = (spouse is mother) ? COL1 : COL2
      // זוג מאותו מין: מקבל קצבת הילדים → COL1, השני → COL2 (רק אם הילד רשום כילדו)
      return Σ_children points(col, ageInYear)  // טבלה טענה 15, כולל דחייה 361/362

points38(joint) = 0.25 + (hasAllowanceChildren ? 1.75 : 1.5)   // 2.0 / 1.75
points39(joint) = hasAllowanceChildren ? 1.75 : 1.5            // חלופה ל־38, לא במצטבר

credit in SEPARATE, per spouse:
  exertionTax  = tax(exertion income only)    // היגיעה בתחתית הסולם
  childCredit  = min(childPoints × 2,904, exertionTax)
  otherCredit  = min(otherPoints × 2,904, totalTax − childCredit)
  // פרשנות לסדר הקיזוז: הילדים נגד מס היגיעה, השאר נגד הכול. זה הסדר המיטיב,
  // והוא אינו משנה תוצאה כשאין הכנסה מרכוש אצל אותו בן זוג.
```

**מה מוחלף במנוע:** בצעד 7 של ב.3 במחקר הקודם — מוחקים את J-max. מחשבים J אחד, בלי נקודות ילדים. הכרעה «צמודה» כבר לא נובעת מ־(ד)-1, ואין חסימה או «אישור משרד» בגללה.

**«חישוב יחיד» (לבן הזוג השני אין יגיעה אישית):** זה (1א), כלומר חישוב נפרד של בעל היגיעה. הוא מקבל **את הטור שלו בלבד**. אם הוא האב והאם אינה עובדת, נקודות טור 1 של האם אובדות. אין הוראה שמעבירה אותן אליו.

### א.3 דוגמה מספרית א׳ — מאוחד חובה, עם ילדים (2026)

**נתונים.** R = הבעל, הכנסה מעסק 300,000. S = האישה, 150,000 מהעסק שלו. התנאים של 66(ד) **לא** התקיימו. שני ילדים, בני 7 ו־10 בשנת המס. נקודה = 2,904 ₪.

- **מס לפני נקודות:** 450,000 → 57,684 + 148,800 × 35% = **109,764**.
- **נקודות R:** 2.25 + 38 (יש ילדים): 2.0 = **4.25** → 12,342.
- **נקודות ילדים: 0.**
- **מס משק הבית: 97,422.**
- **השוואה למה שהמנוע הציג עד היום:** טווח 91,614–97,422 (J-max עם 2 נקודות טור 2 של האב). מעכשיו — **97,422 בלבד**.
- **רגישות לזהות הרשום:** אם האישה הייתה הרשומה, היא מקבלת גם ½ נקודה לפי 36א: 4.75 נקודות → **95,970**.
- **אילו 66(ד) היה מתקיים** (חישוב נפרד מותר): R: 57,312 − 4.25 × 2,904 = **44,970**. S: 19,392 − 6.75 × 2,904 → **0**. סה״כ **44,970**, והרשות הייתה מחילה את הנפרד. הפער של 52,452 ₪ נובע **כולו** מעמידה בתנאי 66(ד). לכן סימון 66(ד) בכרטיס הוא קלט חוסם, כמו שהיה.
