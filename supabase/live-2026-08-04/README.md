# צילום מצב של הפונקציות החיות — 04/08/2026

התיקייה הזו מכילה **העתק מדויק, מילה במילה**, של הפונקציות שרצות בפועל במסד הנתונים
(סכימת `public` בפרויקט Supabase), כפי שנשלפו בתאריך **2026-08-04**, לפני תחילת העבודה
על מסע הקליטה (onboarding journey).

## למה זה כאן

מסד הנתונים הוא מקור האמת. הקבצים כאן הם תמונת מצב בלבד — הם מתעדים מה באמת רץ באותו רגע,
כדי שאפשר יהיה להשוות אליהם אחרי שינויים. אין לערוך אותם ידנית ואין להסיק מהם שהם מעודכנים
לרגע זה; אם המסד השתנה מאז, הקבצים כאן כבר לא משקפים אותו.

## מה יש כאן

23 קבצי `.sql`, אחד לכל פונקציה, בשם הפונקציה. כל קובץ מכיל את הפלט המלא של
`pg_get_functiondef` — בדיוק כפי שהוחזר, בלי עיצוב מחדש, בלי תיקונים ובלי הערות שנוספו.

## איך מרעננים

להריץ מחדש את `pg_get_functiondef` מול המסד ולכתוב את הפלט לקבצים:

```sql
select pg_get_functiondef(oid)
from pg_proc
where pronamespace = 'public'::regnamespace
  and proname = '<שם הפונקציה>';
```
